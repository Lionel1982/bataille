SPRITES & DESSINS DE BATAILLE DE PO/ETS
=======================================

Depose tes images ICI pour remplacer/ajouter des visuels, SANS toucher au code.

DIMENSIONS IMPOSEES (voir PROMPT-IA.txt)
----------------------------------------
  PERSO (4 vues) : canevas 1536x1536, grille 2x2, cases 768x768, marge >=80px, fond BLANC.
  CARTES         : cases 384x384, 4 colonnes, fond TRANSPARENT.
  Les scripts decoupent par grille FIXE ; en secours, ajoute --auto (detection des blocs).

PROMPT POUR L'IA DE DESSIN
--------------------------
  PROMPT-IA.txt  -> prompt MAITRE unique (style Darkstalkers). Il couvre les 2 cas :
      MODE A : planche de PERSONNAGE/FAMILIER en 4 vues (fond BLANC)
      MODE B : planche de DESSINS DE CARTES en grille (fond TRANSPARENT)
  CLES-CARTES.txt -> liste ordonnee des 41 cles de cartes (pour rediger la demande MODE B)

DOSSIERS
--------
  public/sprites/familiers/   -> familiers (chat, chien, bison...)   : 4 vues
  public/sprites/avatars/     -> personnages joueurs (h1..f3)        : 4 vues
  public/sprites/cartes/      -> dessins centraux des cartes (<cle>.png)
  public/sprites/actions/     -> (ancien) dessins d'attaque

======================================================================
PERSONNAGES & FAMILIERS — 4 VUES (front / back / defeated / select)
======================================================================
FORMAT : PNG fond transparent apres decoupe, sujet centre.
NOMMAGE (le nom = la cle utilisee par le jeu) :
  Familiers : <cle>-<vue>.png     ex : chien-front.png, chien-back.png,
                                        chien-defeated.png, chien-select.png
  Avatars   : avatar-<id>-<vue>.png ex : avatar-h1-front.png ... avatar-h1-select.png
  Vues : front (face), back (dos), defeated (KO couche), select (portrait).
  Cles familiers : chat, chien, souris, elephant, bison, serpent, lezard,
                   tortue, poisson, guppy, oiseau, poulet.
  Ids avatars    : h1, h2, h3, f1, f2, f3.

DECOUPE + DECLARATION AUTO (comme les persos) :
  Planche 4 vues (fond blanc) a decouper pour un familier :
    py decouper-perso.py planche-chien.png chien --dest familiers --key chien
  -> ecrit public/sprites/familiers/chien-front.png ... ET declare les vues
     dans src/assets/customSprites.js tout seul (familiers: { chien:[...] }).
  Avatars generiques (h1..f3) : --dest avatars --key h1 (nommage avatar-h1-<vue>.png).
  Les vues non deposees retombent sur l'image integree / placeholder (pas de 404).
  (Tu peux toujours editer customSprites.js a la main si tu preferes.)

======================================================================
DESSINS DE CARTES — planche en grille a decouper
======================================================================
1) Demande a l'IA une PLANCHE EN GRILLE (voir PROMPT-IA.txt, MODE B), fond
   transparent, 1 dessin par case, DANS L'ORDRE d'une liste de cles.
2) Depose la planche a la racine du projet (ex : planche-01.png).
3) Lance la decoupe (ou demande-moi de le faire) :
     py decouper-cartes.py planche-01.png croq os grillon salade morsure ...
   # si la grille n'est pas respectee par l'IA, ajoute --auto :
   py decouper-cartes.py planche-01.png croq os ... --auto
   Le script deduit la grille, decoupe, rogne les marges, ecrit
   public/sprites/cartes/<cle>.png ET met a jour src/assets/cardArt.js tout seul.
4) Les cartes sans dessin gardent leur emoji (repli). Pas de 404.

======================================================================
DESSINS D'ACTION (animations d'attaque) — par cle de SORT
======================================================================
Range : public/sprites/actions/<cle-du-sort>.png   (ex: griffe.png, sumo.png, tsunami.png)
La cle = la cle du SORT dans CARDS (voir CLES-CARTES.txt). Chaque sort peut avoir
SON propre dessin ; sans fichier, il retombe sur l'animation integree partagee.
Apres depot, DECLARE-les :
  - planche a decouper :  py decouper-actions.py planche.png griffe sumo tsunami [--auto]
  - fichiers deja decoupes deposes a la main :  py decouper-actions.py --register griffe sumo
Le script remplit public/sprites/actions/ ET met a jour src/assets/actionArt.js.
