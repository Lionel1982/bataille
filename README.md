# Bataille de Po/ets

Jeu mobile (prototype v3), 100% statique.

## Jouer en local
Ouvrir `index.html` dans un navigateur.

## Mettre en ligne (Vercel)
- Soit : https://vercel.com -> Add New -> Project -> glisser ce dossier `online`.
- Soit (CLI) : `npm i -g vercel` puis dans ce dossier `vercel` puis `vercel --prod`.

## Modifier l'equilibrage
Tout est dans `data.js` (couts, degats, prix). Puis rouvrir `index.html`.
